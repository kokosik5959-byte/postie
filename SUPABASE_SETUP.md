# Подключение Postie к Supabase

После настройки появятся аккаунты, почта Postie, доставка открыток зарегистрированным пользователям и публичные ссылки-приглашения для мессенджеров.

## 1. Создай проект Supabase

Создай проект на [supabase.com/dashboard](https://supabase.com/dashboard). Для проекта понадобятся URL и ключи из **Project Settings → API Keys**.

## 2. Создай таблицы и закрытое хранилище

Открой **SQL Editor → New query**, вставь содержимое файла `supabase/migrations/202610160001_initial_postie.sql` и запусти запрос.

Чтобы включить общий каталог тегов и разрешить их редактирование только владельцу, отдельно запусти SQL из `supabase/migrations/202610160004_catalog_postcard_tags.sql`. Поля доступны всем для просмотра и фильтрации, но добавлять и менять теги может только аккаунт `kokosik5959@gmail.com`.

## 3. Добавь ключи в локальную конфигурацию

В корне проекта создай `.env.local` по образцу `.env.example`:

- `NEXT_PUBLIC_SUPABASE_URL` — Project URL.
- `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` — publishable key (`sb_publishable_…`). Он используется в браузере с включёнными RLS-политиками.
- `SUPABASE_SECRET_KEY` — secret key (`sb_secret_…`). Он нужен только серверу для безопасного показа открыток по публичной ссылке. Не добавляй этот ключ в код браузера и не отправляй его в чат.
- `NEXT_PUBLIC_APP_URL` — локально `http://localhost:3000`; на опубликованном сайте здесь будет его адрес.

Переменные окружения можно скопировать из `.env.example`; вместо примеров вставь значения своего проекта.

## 4. Разреши подтверждение почты

В **Authentication → URL Configuration** укажи Site URL `http://localhost:3000` и добавь Redirect URL `http://localhost:3000/auth/callback`. Для опубликованного сайта добавь его HTTPS-адрес.

Регистрация отправляет пользователю письмо подтверждения. Для реальной доставки писем задай SMTP в **Authentication → SMTP Settings**; встроенная почтовая отправка Supabase предназначена для ограниченного тестирования.

## 5. Перезапусти приложение

После сохранения `.env.local` перезапусти сервер из PowerShell:

```powershell
npm.cmd run dev
```

Открой `http://localhost:3000`, зайди в **Профиль → Войти или создать аккаунт Postie**.

## Как будут работать открытки

- Отправка на почту существующего пользователя создаёт запись в его «Полученных».
- Для мессенджера включи **«Ссылка для мессенджера»** и отправь созданную ссылку через меню телефона или скопируй её. Получатель увидит открытку без аккаунта.
- Загруженные личные фото помещаются в закрытое хранилище; публичная страница получает временную ссылку на изображение после проверки уникального токена открытки.
